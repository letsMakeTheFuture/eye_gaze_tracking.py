# Iris Detection 👁️

A real-time iris detection and gaze-tracking prototype built with **Python, OpenCV, MediaPipe Face Mesh, and NumPy**.

### Features

* Real-time iris landmark detection
* Eye position and gaze estimation
* Webcam-based processing
* Directional command detection

### Technologies

**Python · OpenCV · MediaPipe · NumPy**

> Developed as part of the **EYRA** assistive eye-control project.
